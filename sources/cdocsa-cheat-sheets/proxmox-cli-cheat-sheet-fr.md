Arrêt propre via ACPI\nqm reboot 100                   # Redémarrage propre via ACPI\nqm reset 100                    # Réinitialisation matérielle (immédiate)\nqm suspend 100                  # Mettre en pause la VM (RAM)\nqm resume 100                   # Reprendre une VM suspendue\n\n# Informations sur une VM\nqm status 100                   # Obtenir l'état actuel\nqm config 100                   # Afficher la configuration complète\nqm pending 100                  # Afficher les modifications en attente\nqm showcmd 100                  # Afficher la ligne de commande QEMU générée\n\n# Créer et cloner des VM\nqm create 101 --name mavm --memory 2048 --cores 2 --net0 virtio,bridge=vmbr0\nqm clone 100 101 --name clone-vm --full   # Définir 4 cœurs CPU\nqm set 100 --net0 virtio,bridge=vmbr0,tag=10  # Ajouter un tag VLAN\nqm set 100 --boot order=scsi0   # Définir l'ordre de démarrage\n\n# Opérations sur les disques\nqm disk resize 100 scsi0 +10G   # Agrandir le disque de 10 Go\nqm disk move 100 scsi0 local-lvm  # Déplacer le disque vers un autre stockage\nqm disk unlink 100 --idlist unused0  # Supprimer la référence d'un disque inutilisé\nqm disk import 100 disk.qcow2 local-lvm  # Importer une image disque (forme canonique)\n\n# Instantanés (snapshots)\nqm snapshot 100 snap1 --description \"Avant les mises à jour\"\nqm listsnapshot 100             # Lister les instantanés\nqm rollback 100 snap1           # Restaurer un instantané\nqm delsnapshot 100 snap1        # Supprimer un instantané\n\n# Import/Export\nqm importovf 100 vm.ovf local-lvm  # Importer depuis un fichier OVF/OVA\n\n# Modèles (Templates)\nqm template 100                 # Convertir une VM en modèle\n\n# Migration\nqm migrate 100 node2 --online   # Migration à chaud vers un autre nœud\nqm migrate 100 node2            # Migration à froid (VM éteinte)\n\n# Accès au terminal série et agent invité\nqm terminal 100                 # Ouvrir un terminal série sur la VM\nqm guest exec 100 -- ls /       # Exécuter une commande via l'agent QEMU\nqm guest passwd 100 root        # Changer le mot de passe via l'agent invité\n\n# Supprimer une VM\nqm destroy 100                  # Supprimer la VM et ses disques\nqm destroy 100 --purge          # Supprimer aussi des tâches de sauvegarde\n```\n\n> **Note :** `qm importdisk` est un alias de `qm disk import` — les deux fonctionnent.\n\n---\n\n## Gestion des conteneurs (pct)\n\n```bash\n# Lister les conteneurs\npct list                        # Afficher tous les conteneurs LXC\n\n# Cycle de vie d'un conteneur\npct start 200                   # Démarrer le conteneur\npct stop 200                    # Arrêter le conteneur (brutal)\npct shutdown 200                # Arrêt propre du conteneur\npct reboot 200                  # Redémarrer le conteneur\n\n# Informations sur un conteneur\npct status 200                  # Obtenir l'état\npct config 200                  # Afficher la configuration complète\npct df 200                      # Afficher l'utilisation des disques du CT\n\n# Créer un conteneur\npct create 201 local:vztmpl/debian-12-standard_12.2-1_amd64.tar.zst \\\n    --hostname monconteneur \\\n    --memory 512 \\\n    --cores 1 \\\n    --net0 name=eth0,bridge=vmbr0,ip=dhcp \\\n    --rootfs local-lvm:8        # Disque racine de 8 Go\n\n# Cloner un conteneur\npct clone 200 201 --hostname clone-ct --full\n\n# Modifier la configuration du conteneur\npct set 200 --memory 1024       # Changer la RAM\npct set 200 --cores 2           # Changer les cœurs CPU\npct set 200 --hostname nouveau  # Changer le nom d'hôte\npct set 200 --net0 name=eth0,bridge=vmbr0,ip=192.168.1.100/24,gw=192.168.1.1\n\n# Points de montage\npct set 200 --mp0 local-lvm:10,mp=/data  # Ajouter un point de montage de 10 Go\n\n# Accès au conteneur\npct enter 200                   # Ouvrir un shell dans le conteneur (via lxc-attach)\npct console 200                 # Se connecter à la console tty du conteneur\npct exec 200 -- apt update      # Exécuter une commande dans le conteneur\npct push 200 /local/fichier /chemin/ct    # Copier un fichier vers le conteneur\npct pull 200 /chemin/ct /local/fichier    # Copier un fichier depuis le conteneur\n\n# Instantanés (snapshots)\npct snapshot 200 snap1          # Créer un instantané\npct listsnapshot 200            # Lister les instantanés\npct rollback 200 snap1          # Restaurer un instantané\npct delsnapshot 200 snap1       # Supprimer un instantané\n\n# Modèles (Templates)\npct template 200                # Convertir en modèle\n\n# Redimensionner\npct resize 200 rootfs +5G       # Agrandir le rootfs de 5 Go\n\n# Maintenance du système de fichiers\npct fstrim 200                  # Libérer l'espace inutilisé (discard/trim)\npct fsck 200                    # Vérifier le système de fichiers (CT arrêté requis)\n\n# Montage/Démontage d'urgence\npct mount 200                   # Monter le système de fichiers du conteneur\npct unmount 200                 # Démonter le système de fichiers du conteneur\n\n# Déplacement de volumes\npct move-volume 200 rootfs local-lvm  # Déplacer un volume vers un autre stockage\n\n# Migration\npct migrate 200 node2           # Migrer vers un autre nœud\npct migrate 200 node2 --restart # Redémarrer après la migration\n\n# Supprimer\npct destroy 200                 # Afficher tous les stockages avec utilisation\npvesm list local-lvm            # Lister le contenu d'un stockage spécifique\npvesm list local --content backup  # Lister uniquement les sauvegardes\n\n# Ajouter un stockage\npvesm add dir monstockage --path /mnt/data  # Proxmox Backup Server\n\n# Supprimer un stockage\npvesm remove monstockage        # Supprimer la définition du stockage\n\n# Types de contenu\npvesm set local --content iso,vztmpl,backup  # Définir les types autorisés\n# Types disponibles : iso, vztmpl, backup, images, rootdir, snippets\n\n# Télécharger des modèles (templates)\npveam update                    # Mettre à jour la liste des modèles\npveam available                 # Lister les modèles disponibles\npveam available --section system # Lister les modèles système uniquement\npveam download local debian-12-standard_12.2-1_amd64.tar.zst\n\n# Scanner les ressources de stockage\npvesm scan nfs 192.168.1.10     # Scanner les exports NFS\npvesm scan cifs 192.168.1.10    # Scanner les partages CIFS/SMB\npvesm scan iscsi 192.168.1.10   # Scanner les cibles iSCSI\npvesm scan lvm                  # Scanner les groupes de volumes LVM\npvesm scan lvmthin vgname       # Scanner les pools thin LVM\npvesm scan zfs                  # Scanner les pools ZFS\npvesm scan pbs 192.168.1.20 --username user@pbs  # Scanner PBS\n\n# Allouer/Libérer des volumes\npvesm alloc local-lvm 100 '' 10G  # Allouer un volume de 10 Go\npvesm free local-lvm:vm-100-disk-0  # Libérer un volume\n\n# Gestion de la rétention des sauvegardes\npvesm prune-backups local --keep-last 5 --keep-daily 7  # Nettoyer les anciennes sauvegardes\n```\n\n> **Types de stockage supportés (PVE 9.x) :** btrfs, cephfs, cifs, dir, esxi, iscsi, iscsidirect, lvm, lvmthin, nfs, pbs, rbd, zfs, zfspool.\n\n---\n\n## Sauvegarde et restauration (vzdump)\n\n```bash\n# Sauvegarder une VM ou un conteneur\nvzdump 100                      # Sauvegarder la VM 100 vers le stockage par défaut\nvzdump 100 --storage backup-store  # Sauvegarder vers un stockage spécifique\nvzdump 100 --mode snapshot      # Mode instantané (recommandé pour les VM en cours)\nvzdump 100 --mode suspend       # Mode suspension (courte interruption)\nvzdump 100 --mode stop          # Mode arrêt (consistance maximale)\nvzdump 100 --compress zstd      # Compresser avec zstd (meilleur ratio/vitesse)\nvzdump 100 --compress gzip      # Sauvegarder toutes les VM d'un pool\n\n# Sauvegarde avec notes dynamiques (template)\nvzdump 100 --notes-template '{{guestname}} - sauvegarde avant mise à jour'\n# Variables disponibles : {{cluster}}, {{guestname}}, {{node}}, {{vmid}}\n\n# Rétention des sauvegardes\nvzdump 100 --prune-backups keep-last=3,keep-daily=7,keep-weekly=4,keep-monthly=6\n\n# Sauvegarde protégée (ne peut pas être supprimée automatiquement)\nvzdump 100 --storage backup --protected 1\n\n# Limiter la bande passante\nvzdump 100 --bwlimit 10240      # Limiter à 10 Mo/s (valeur en Ko/s)\n\n# Sauvegarde avec fleecing (améliore les performances I/O de la VM pendant la sauvegarde)\nvzdump 100 --fleecing enabled=1,storage=local-lvm\n\n# Lister les sauvegardes (via pvesm, pas vzdump)\npvesm list local --content backup        # Restaurer sur un stockage spécifique\n\n# Restaurer un conteneur\npct restore 200 /var/lib/vz/dump/vzdump-lxc-200-2026_01_30-12_00_00.tar.zst\npct restore 200 backup.tar.zst --storage local-lvm --hostname ct-restaure\n\n# Restauration avec limite de bande passante\nqmrestore backup.vma.zst 100 --bwlimit 10240\n\n# Restauration en direct (Live-Restore) — uniquement depuis Proxmox Backup Server\nqmrestore backup.vma 100 --live-restore  #
