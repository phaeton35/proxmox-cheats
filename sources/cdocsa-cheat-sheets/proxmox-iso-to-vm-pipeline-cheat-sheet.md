Create the Base VM\n\n```bash\n# ── Variables (adjust to your environment) ──\nVMID=9000                     # Template VMID (use 9xxx convention)\nNAME=\"template-alpine-321\"    # VM name\nISO=\"alpine-virt-3.21.0-x86_64.iso\"\nSTORAGE=\"local-lvm\"           # Disk storage\nBRIDGE=\"vmbr0\"                # Network bridge\nCORES=2\nRAM=1024                      # MB\nDISK=8                        # GB\n\n# ── Create the VM ──\nqm create $VMID \\\n  --name $NAME \\\n  --ostype l26 \\\n  --machine q35 \\\n  --cpu cputype=host \\\n  --cores $CORES \\\n  --memory $RAM \\\n  --balloon 512 \\\n  --net0 virtio,bridge=$BRIDGE \\\n  --scsihw virtio-scsi-single \\\n  --scsi0 ${STORAGE}:${DISK},iothread=1,discard=on,ssd=1 \\\n  --ide2 local:iso/${ISO},media=cdrom \\\n  --boot order=ide2 \\\n  --serial0 socket \\\n  --vga serial0 \\\n  --agent enabled=1\n```\n\n### 2b. Unattended Install — Per OS Family\n\nEach OS has its own answer file mechanism. and prepare it for template conversion.\n\n```bash\n# ── SSH into the freshly installed VM ──\nssh root@<vm-ip>\n```\n\n### 3a. Install Cloud-Init + Guest Agent\n\n```bash\n# ── Alpine ──\napk update && apk upgrade\napk add cloud-init qemu-guest-agent bash curl sudo\nrc-update add cloud-init-local boot\nrc-update add cloud-init default\nrc-update add cloud-config default\nrc-update add cloud-final default\nrc-update add qemu-guest-agent default\n\n# ── Debian / Ubuntu ──\napt update && apt upgrade -y\napt install -y cloud-init qemu-guest-agent curl sudo\nsystemctl enable cloud-init qemu-guest-agent\n\n# ── Rocky / RHEL / Alma ──\ndnf update -y\ndnf install -y cloud-init qemu-guest-agent curl sudo\nsystemctl enable cloud-init qemu-guest-agent\n```\n\n### 3b. Configure Cloud-Init Datasource (Proxmox uses NoCloud)\n\n```bash\n# All distros — tell cloud-init to look for Proxmox data\ncat > /etc/cloud/cloud.cfg.d/99_proxmox.cfg << 'EOF'\ndatasource_list: [NoCloud, ConfigDrive, None]\ndatasource:\n  NoCloud:\n    seedfrom: /\nEOF\n```\n\n### 3c. Clean Up Before Templating\n\n```bash\n# ── Generic cleanup (run on any distro) ──\n\n# Remove SSH host keys (cloud-init regenerates them)\nrm -f /etc/ssh/ssh_host_*\n\n# Clear machine-id (cloud-init regenerates it)\ntruncate -s 0 /etc/machine-id\nrm -f /var/lib/dbus/machine-id\n\n# Clear cloud-init state so it runs on next boot\ncloud-init clean --logs\n\n# Clear logs and temp files\nfind /var/log -type f -exec truncate -s 0 {} \\;\nrm -rf /tmp/* /var/tmp/*\n\n# Clear shell history\nrm -f /root/.bash_history /root/.ash_history\nhistory -c\n\n# ── Alpine-specific ──\nrm -rf /var/cache/apk/*\n\n# ── Debian/Ubuntu-specific ──\napt clean && rm -rf /var/lib/apt/lists/*\n\n# ── RHEL/Rocky-specific ──\ndnf clean all && rm -rf /var/cache/dnf/*\n\n# Sync and shut down\nsync\npoweroff\n```\n\n---\n\n## Step 4 — Convert to Template\n\n```bash\n# ── Remove the CD-ROM / ISO ──\nqm set $VMID --ide2 none\n\n# ── Add a cloud-init drive ──\nqm set $VMID --ide2 ${STORAGE}:cloudinit\n\n# ── Set boot order to disk only ──\nqm set $VMID --boot order=scsi0\n\n# ── Convert VM to template ──\nqm template $VMID\n\n# ── Verify ──\nqm list | grep $VMID\n# Should show \"template\" in the status column\n```\n\n> **Warning:** `qm template` is **irreversible**. The VM becomes read-only. You can only clone from it, not start it.\n\n---\n\n## Step 5 — Clone with Cloud-Init → Running VM\n\n### 5a. Full Clone (Independent Disk)\n\n```bash\n# ── Variables ──\nTEMPLATE=9000\nNEW_VMID=301\nNEW_NAME=\"alpine-web-01\"\nIP=\"192.168.1.101/24\"\nGW=\"192.168.1.1\"\nSSH_KEY_FILE=\"$HOME/.ssh/id_ed25519.pub\"\n\n# ── Clone ──\nqm clone $TEMPLATE $NEW_VMID --name $NEW_NAME --full\n\n# ── Configure cloud-init ──\nqm set $NEW_VMID \\\n  --ciuser srvadmin \\\n  --sshkeys $SSH_KEY_FILE \\\n  --ipconfig0 ip=$IP,gw=$GW \\\n  --nameserver \"86.54.11.13 9.9.9.9\" \\\n  --searchdomain home.lab\n\n# ── Optionally resize disk ──\nqm disk resize $NEW_VMID scsi0 +20G\n\n# ── Optionally change hardware ──\nqm set $NEW_VMID --cores 4 --memory 4096\n\n# ── Start ──\nqm start $NEW_VMID\n```\n\n### 5b. Linked Clone (Shares Base Disk — Faster, Less Space)\n\n```bash\n# Linked clone (copy-on-write, depends on template disk)\nqm clone $TEMPLATE $NEW_VMID --name $NEW_NAME\n# Note: no --full flag = linked clone\n```\n\n### 5c. Batch Deploy (Shell Loop)\n\n```bash\n#!/usr/bin/env bash\n# batch-clone.sh — Deploy multiple VMs from a template\nset -euo pipefail\n\nTEMPLATE=9000\nSSH_KEY_FILE=\"$HOME/.ssh/id_ed25519.pub\"\nDOMAIN=\"home.lab\"\nDNS=\"86.54.11.13 9.9.9.9\"\nGW=\"192.168.1.1\"\n\n# Define VMs: VMID NAME IP CORES RAM(MB)\nVMS=(\n  \"301 alpine-web-01  192.168.1.101/24 2 2048\"\n  \"302 alpine-db-01   192.168.1.102/24 4 4096\"\n  \"303 alpine-app-01  192.168.1.103/24 2 2048\"\n  \"304 alpine-mon-01  192.168.1.104/24 2 2048\"\n)\n\nfor entry in \"${VMS[@]}\"; do\n  read -r VMID NAME IP CORES RAM <<< \"$entry\"\n  echo \"═══ Deploying $NAME (VM $VMID) ═══\"\n\n  qm clone $TEMPLATE $VMID --name \"$NAME\" --full\n  qm set $VMID \\\n    --ciuser srvadmin \\\n    --sshkeys \"$SSH_KEY_FILE\" \\\n    --ipconfig0 \"ip=${IP},gw=${GW}\" \\\n    --nameserver \"$DNS\" \\\n    --searchdomain \"$DOMAIN\" \\\n    --cores \"$CORES\" \\\n    --memory \"$RAM\"\n  qm start $VMID\n\n  echo \"  ✓ $NAME started at ${IP%%/*}\"\ndone\n\necho \"\"\necho \"All VMs deployed. Wait ~30s for cloud-init, then SSH:\"\nfor entry in \"${VMS[@]}\"; do\n  read -r VMID NAME IP _ _ <<< \"$entry\"\n  echo \"  ssh srvadmin@${IP%%/*}    # $NAME\"\ndone\n```\n\n---\n\n## Cloud-Init
