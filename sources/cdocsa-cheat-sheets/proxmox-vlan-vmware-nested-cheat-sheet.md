Tagged frames are silently dropped. A VLAN-aware bridge in nested Proxmox will not pass tagged traffic through a vmnet interface.\n\n---\n\n## Strategy 1 — One vmnet per VLAN (Simplest)\n\nCreate multiple virtual NICs in VMware VM settings, each on a separate Custom vmnet. Map each to a non-VLAN-aware Proxmox bridge.\n\n### VMware VM Settings (.vmx)\n\n```bash\nethernet0.connectionType = \"custom\"    # First NIC → vmnet1 (\"VLAN 10\")\nethernet0.vnet           = \"vmnet1\"\nethernet1.connectionType = \"custom\"    # Second NIC → vmnet2 (\"VLAN 20\")\nethernet1.vnet           = \"vmnet2\"\nethernet2.connectionType = \"custom\"    # Third NIC → vmnet3 (\"VLAN 30\")\nethernet2.vnet           = \"vmnet3\"\n```\n\n### Proxmox /etc/network/interfaces\n\n```bash\nauto vmbr0\niface vmbr0 inet static\n    address 10.10.0.1/24\n    bridge-ports ens32             # vmnet1 → \"VLAN 10\" traffic\n    bridge-stp off\n    bridge-fd 0\n\nauto vmbr1\niface vmbr1 inet static\n    address 10.20.0.1/24\n    bridge-ports ens33             # vmnet2 → \"VLAN 20\" traffic\n    bridge-stp off\n    bridge-fd 0\n\nauto vmbr2\niface vmbr2 inet static\n    address 10.30.0.1/24\n    bridge-ports ens34             # vmnet3 → \"VLAN 30\" traffic\n    bridge-stp off\n    bridge-fd 0\n```\n\n> 💡 No `bridge-vlan-aware` needed — each bridge carries a single flat network, no tags on the wire.\n\n---\n\n## Strategy 2 — Bridged Mode to Physical Trunk Port\n\nIf the physical host NIC is connected to a real switch trunk port, use **Bridged** networking in VMware. Tagged frames pass through the physical NIC untouched.\n\n### VMware VM Settings (.vmx)\n\n```bash\nethernet0.connectionType = \"bridged\"   # Pass-through to physical NIC\nethernet0.noPromisc      = \"FALSE\"     # Allow promiscuous mode\n```\n\n### Proxmox /etc/network/interfaces\n\n```bash\nauto vmbr0\niface vmbr0 inet manual\n    bridge-ports ens32             # Physical bridged NIC (receives trunk)\n    bridge-stp off\n    bridge-fd 0\n    bridge-vlan-aware yes          # ✅ VLAN-aware works — real trunk\n    bridge-vids 2-4094             # Allow all VLANs\n```\n\n### Assign VLANs to VMs\n\n```bash\nqm set 100 --net0 virtio,bridge=vmbr0,tag=10    # VM 100 on VLAN 10\nqm set 101 --net0 virtio,bridge=vmbr0,tag=20    # VM 101 on VLAN 20\nqm set 102 --net0 virtio,bridge=vmbr0,tag=30    # VM 102 on VLAN 30\n```\n\n---\n\n## Strategy 3 — VLAN-Aware Purely Internal to Proxmox\n\nWhen VLANs only need to work **between VMs inside Proxmox** (no traffic leaving to VMware's network), VLAN-aware bridges work fine — tags never hit the vmnet.\n\n### Proxmox /etc/network/interfaces\n\n```bash\n# Management bridge (external, no VLANs)\nauto vmbr0\niface vmbr0 inet static\n    address 192.168.1.10/24\n    gateway 192.168.1.1\n    bridge-ports ens32             # To VMware vmnet for management\n    bridge-stp off\n    bridge-fd 0\n\n# Internal-only VLAN-aware bridge (no physical ports)\nauto vmbr1\niface vmbr1 inet manual\n    bridge-ports none              # No physical uplink — internal only\n    bridge-stp off\n    bridge-fd 0\n    bridge-vlan-aware yes          # ✅ Works — tags stay inside Proxmox\n    bridge-vids 2-4094\n```\n\n### Assign Internal VLANs\n\n```bash\nqm set 100 --net0 virtio,bridge=vmbr0             # Management NIC\nqm set 100 --net1
