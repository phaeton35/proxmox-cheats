Shows VMID, name, status, memory, disk\n\n# VM lifecycle\nqm start 100                    # Start VM with ID 100\nqm stop 100                     # Hard stop (like pulling power)\nqm shutdown 100                 # Graceful ACPI shutdown\nqm reboot 100                   # Graceful reboot via ACPI\nqm reset 100                    # Hard reset (immediate)\nqm suspend 100                  # Suspend VM to RAM\nqm resume 100                   # Resume suspended VM\n\n# VM information\nqm status 100                   # Get current status\nqm config 100                   # Show full config\nqm pending 100                  # Show pending config changes\nqm showcmd 100                  # Show QEMU command line\n\n# Create and clone VMs\nqm create 101 --name myvm --memory 2048 --cores 2 --net0 virtio,bridge=vmbr0\nqm clone 100 101 --name cloned-vm --full  # Full clone (independent copy)\nqm clone 100 101 --name linked-vm         # Linked clone (shares base disk)\n\n# Modify VM configuration\nqm set 100 --memory 4096        # Change RAM to 4GB\nqm set 100 --cores 4            # Set 4 CPU cores\nqm set 100 --net0 virtio,bridge=vmbr0,tag=10  # Add VLAN tag\nqm set 100 --boot order=scsi0   # Set boot order\n\n# Disk operations\nqm disk resize 100 scsi0 +10G   # Increase disk by 10GB\nqm disk move 100 scsi0 local-lvm  # Move disk to different storage\nqm disk unlink 100 --idlist unused0  # Remove unused disk reference\nqm disk import 100 disk.qcow2 local-lvm  # Import disk image (canonical form)\n\n# Snapshots\nqm snapshot 100 snap1 --description \"Before updates\"\nqm listsnapshot 100             # List snapshots\nqm rollback 100 snap1           # Rollback to snapshot\nqm delsnapshot 100 snap1        # Delete snapshot\n\n# Import/Export\nqm importovf 100 vm.ovf local-lvm  # Import OVF/OVA\n\n# Templates\nqm template 100                 # Convert VM to template\n\n# Migration\nqm migrate 100 node2 --online   # Live migrate to another node\nqm migrate 100 node2            # Offline migrate\n\n# Serial terminal & guest agent\nqm terminal 100                 # Open serial terminal to VM\nqm guest exec 100 -- ls /       # Run command via QEMU guest agent\nqm guest passwd 100 root        # Change password via guest agent\n\n# Delete VM\nqm destroy 100                  # Delete VM and disks\nqm destroy 100 --purge          # Also remove from backup jobs\n```\n\n> **Note:** `qm importdisk` is an alias for `qm disk import` — both work.\n\n---\n\n## Container Management (pct)\n\n```bash\n# List containers\npct list                        # Show all LXC containers\n\n# Container lifecycle\npct start 200                   # Start container\npct stop 200                    # Stop container\npct shutdown 200                # Graceful shutdown\npct reboot 200                  # Reboot container\n\n# Container info\npct status 200                  # Get status\npct config 200                  # Show full config\npct df 200                      # Show container disk usage\n\n# Create containers\npct create 201 local:vztmpl/debian-12-standard_12.2-1_amd64.tar.zst \\\n    --hostname mycontainer \\\n    --memory 512 \\\n    --cores 1 \\\n    --net0 name=eth0,bridge=vmbr0,ip=dhcp \\\n    --rootfs local-lvm:8        # 8GB root disk\n\n# Clone container\npct clone 200 201 --hostname clone-ct --full\n\n# Modify container\npct set 200 --memory 1024       # Change RAM\npct set 200 --cores 2           # Change CPU cores\npct set 200 --hostname newname  # Change hostname\npct set 200 --net0 name=eth0,bridge=vmbr0,ip=192.168.1.100/24,gw=192.168.1.1\n\n# Mount points\npct set 200 --mp0 local-lvm:10,mp=/data  # Add 10GB mountpoint at /data\n\n# Container access\npct enter 200                   # Enter container shell (via lxc-attach)\npct console 200                 # Connect to container TTY console\npct exec 200 -- apt update      # Run command in container\npct push 200 /local/file /container/path  # Copy file to container\npct pull 200 /container/path /local/file  # Copy file from container\n\n# Snapshots\npct snapshot 200 snap1          # Create snapshot\npct listsnapshot 200            # List snapshots\npct rollback 200 snap1          # Rollback\npct delsnapshot 200 snap1       # Delete snapshot\n\n# Templates\npct template 200                # Convert to template\n\n# Resize\npct resize 200 rootfs +5G       # Increase rootfs by 5GB\n\n# Filesystem maintenance\npct fstrim 200                  # Reclaim unused space (discard/trim)\npct fsck 200                    # Check filesystem (container must be stopped)\n\n# Mount/Unmount (emergency access)\npct mount 200                   # Mount container filesystem on host\npct unmount 200                 # Unmount container filesystem\n\n# Move volumes\npct move-volume 200 rootfs local-lvm  # Move volume to different storage\n\n# Migration\npct migrate 200 node2           # Migrate to another node\npct migrate 200 node2 --restart # Restart after migration\n\n# Delete\npct destroy 200                 # Delete container\npct destroy 200 --purge         # Also remove from backup jobs\n```\n\n> **Note:** `pct enter` opens a shell via `lxc-attach`, while `pct console` connects to the container's TTY.\n> `pct suspend` exists but is **experimental** in PVE 9.x.\n\n---\n\n## Storage Management (pvesm)\n\n```bash\n# List storage pools\npvesm status                    # Show all storage with usage\npvesm list local-lvm            # List content of specific storage\npvesm list local --content backup  # List only backups on a storage\n\n# Add storage\npvesm add dir mystg --path /mnt/data  # Add directory storage\npvesm add nfs nfsstorage --server 192.168.1.10 --export /share  # NFS\npvesm add lvmthin lvmthin1 --vgname pve --thinpool data  # LVM-Thin\npvesm add pbs pbs1 --server 192.168.1.20 --datastore store1  # Proxmox Backup Server\n\n# Remove storage\npvesm remove mystg              # Remove storage definition\n\n# Content types\npvesm set local --content iso,vztmpl,backup  # Set allowed content types\n# Available types: iso, vztmpl, backup, images, rootdir, snippets\n\n# Download templates\npveam update                    # Update template list\npveam available                 # List available templates\npveam available --section system # List only system templates\npveam download local debian-12-standard_12.2-1_amd64.tar.zst\n\n# Storage scan\npvesm scan nfs 192.168.1.10     # Scan NFS exports\npvesm scan cifs 192.168.1.10    # Scan CIFS/SMB shares\npvesm scan iscsi 192.168.1.10   # Scan iSCSI targets\npvesm scan lvm                  # Scan LVM volume groups\npvesm scan lvmthin vgname       # Scan LVM thin pools\npvesm scan zfs                  # Scan ZFS pools\npvesm scan pbs 192.168.1.20 --username user@pbs  # Scan PBS datastores\n\n# Allocate/Free volumes\npvesm alloc local-lvm 100 '' 10G  # Allocate 10GB volume\npvesm free local-lvm:vm-100-disk-0  # Free volume\n\n# Backup retention management\npvesm prune-backups local --keep-last 5 --keep-daily 7  # Prune old backups\n```\n\n> **Supported storage types (PVE 9.x):** btrfs, cephfs, cifs, dir, esxi, iscsi, iscsidirect, lvm, lvmthin, nfs, pbs, rbd, zfs, zfspool.\n\n---\n\n## Backup and Restore (vzdump)\n\n```bash\n# Backup VM/Container\nvzdump 100                      # Backup VM 100 to default storage\nvzdump 100 --storage backup-store  # Backup to specific storage\nvzdump 100 --mode snapshot      # Snapshot mode (recommended for running VMs)\nvzdump 100 --mode suspend       # Suspend mode (brief downtime)\nvzdump 100 --mode stop          # Stop mode (full consistency)\nvzdump 100 --compress zstd      # Compress with zstd (best speed/ratio)\nvzdump 100 --compress gzip      # Compress with gzip\nvzdump 100 --compress lzo       # Compress with lzo\n\n# Backup multiple VMs\nvzdump 100 101 102 --compress zstd --storage backup\nvzdump --all --exclude 100,101  # Backup all except 100 and 101\nvzdump --pool mypool            # Backup all guests in a pool\n\n# Backup with notes template\nvzdump 100 --notes-template '{{guestname}} - pre-upgrade backup'\n# Available variables: {{cluster}}, {{guestname}}, {{node}}, {{vmid}}\n\n# Backup retention\nvzdump 100 --prune-backups keep-last=3,keep-daily=7,keep-weekly=4,keep-monthly=6\n\n# Protected backup (cannot be pruned automatically)\nvzdump 100 --storage backup --protected 1\n\n# Bandwidth limit\nvzdump 100 --bwlimit 10240      # Limit to 10 MB/s (value in KB/s)\n\n# Backup fleecing (improves guest IO during backup, VM only)\nvzdump 100 --fleecing enabled=1,storage=local-lvm\n\n# List backups (use pvesm, not vzdump)\npvesm list local --content backup         # List local backups\npvesm list backup-store --content backup  # List backups on specific storage\n\n# Restore VM\nqmrestore /var/lib/vz/dump/vzdump-qemu-100-2026_01_30-12_00_00.vma.zst 100\nqmrestore backup.vma.zst 100 --storage local-lvm  # Restore to specific storage\nqmrestore backup.vma.zst 100 --bwlimit 10240      # Restore with bandwidth limit\n\n# Restore container\npct restore 200 /var/lib/vz/dump/vzdump-lxc-200-2026_01_30-12_00_00.tar.zst\npct restore 200 backup.tar.zst --storage local-lvm --hostname restored-ct\n\n# Live-Restore (Proxmox Backup Server only — VM starts during restore)\nqmrestore backup.vma 100 --live-restore\n\n# Clone via pipe (advanced)\nvzdump 101 --stdout | pct restore 300 - --rootfs 4\n```\n\n> **Warning:** `vzdump list` is **NOT** a valid command. To list backups, use `pvesm list <storage> --content backup`.\n> The `--notes` option does not exist — use `--notes-template` instead.\n\n---\n\n## Cluster Management (pvecm)\n\n```bash\n# Cluster           # Remove QDevice\n\n# Certificates\npvecm updatecerts               # Update cluster certificates\npvecm updatecerts --force       # Force SSL certificate regeneration\n```\n\n> **Cluster
